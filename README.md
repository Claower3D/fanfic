# 🌹 SLX Fanfics — Архив Фанфиков Discord Сервера

Полнофункциональный веб-сервис для публикации, чтения и каталогизации фанфиков по участникам Discord-сервера **SLX**.

Сервис работает на **React 19 + TypeScript + Tailwind CSS** на фронтенде и **Node.js (Express) + SQLite** на бэкенде.

---

## ✨ Возможности

- **Персонажи сервера**: список участников с цветными ролями, цитатами, статистикой и персональной страницей для каждого мембера.
- **Публикация фанфиков**: создание историй, глав, выбор персонажей, тегов, рейтингов (G, PG-13, R-16, NC-17).
- **Режим чтения**: настройка шрифта, размера текста, темы (Discord, Полночь, Сепия, OLED), звуковой амбиент и встроенная озвучка (TTS).
- **Реакции и обсуждения**: эмодзи-реакции и комментарии от участников сервера.
- **База данных SQLite**: все истории, персонажи, реакции и комментарии сохраняются в постоянную базу данных на сервере.
- **Готов к деплою на Railway**: Dockerfile и `railway.json` уже настроены.

## 🚀 Деплой на Railway (1-click через GitHub)

1. Загрузите проект в ваш GitHub репозиторий:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git remote add origin https://github.com/ВАШ_АККАУНТ/РЕПОЗИТОРИЙ.git
   git push -u origin main
   ```

2. Откройте **[railway.app](https://railway.app)** и нажмите **New Project** -> **Deploy from GitHub repo**.
3. Выберите ваш репозиторий. Railway автоматически обнаружит `railway.json` и `Dockerfile`, соберет проект и запустит сервер.
4. **Постоянное хранение данных (Volume)**:
   - В Railway перейдите во вкладку вашего сервиса -> **Volumes**.
   - Нажмите **Add Volume**.
   - Укажите точку монтирования: `/app/data`.
   - Теперь база данных SQLite (`/app/data/fanfics.sqlite`) будет сохранять все данные даже при перезапусках и обновлениях контейнера!

## 💻 Локальный запуск

### Вариант 1: Через Node.js
```bash
# 1. Установка зависимостей
npm install

# 2. Сборка фронтенда
npm run build

# 3. Запуск сервера (бэкенд + фронтенд)
npm start
```
Сервис откроется по адресу: **http://localhost:3000**

### Вариант 2: Через Docker
```bash
docker compose up --build
```
Сервис откроется по адресу: **http://localhost:3000**
База данных сохраняется в локальную папку `./data`.
